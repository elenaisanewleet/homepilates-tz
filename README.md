# HomePilates · перенос в Тильду

Локальный просмотр — открыть `site/index.html` двойным щелчком. Шрифты, фотографии, меню и таблицы работают с диска. Для расписания, кабинета, отзывов и карты нужен интернет. [Предпросмотр на Vercel](https://homepilates-tz.vercel.app/).

## Порядок вставки

1. В проекте **classes.homepilates.ru** создайте страницы из таблицы. Назначьте «Главная» главной страницей проекта. Сохраните существующие страницы `/privacy_policy` и `/approval`.
2. На **каждой** странице добавьте два блока **Другое → T123 «HTML-код»**. В содержимое первого целиком вставьте `tilda/common.html`, в содержимое второго — соответствующий файл из таблицы. Опубликуйте страницы. Шрифты и фото фрагментов загружаются по HTTPS с закреплённой версии материалов. [Вставка HTML в Тильде](https://help-ru.tilda.cc/html).
3. Меню, бургер, подвал и кнопка кабинета уже находятся во втором блоке. Уберите прежнюю сквозную шапку и подвал с этих восьми страниц. В настройках SEO каждой страницы укажите заголовок «название страницы — HomePilates», а для description скопируйте значение соответствующего ключа из `content.json → seo` (ключ главной — пустая строка). В настройках сайта → SEO → редиректы страниц внесите подтверждённые пары старый путь → новый путь. Главная сохраняет адрес `/`. Старые якоря с # обрабатываются браузером, для них нужны якоря или клиентские переходы. [Адреса страниц](https://help-ru.tilda.cc/link-to-page) · [Редиректы](https://help-ru.tilda.cc/redirect).
4. Для **Метрики и cookie** используется собственный баннер и счётчик 51299566. Удалите дубли этого счётчика из встроенной аналитики, HTML и менеджера тегов. Отключите второй cookie-баннер. Технические включены постоянно. Аналитические запускают счётчик только после сохранения согласия. Рекламные сохраняют отдельный выбор, рекламные сети в материалах не заданы. Настройки повторно открываются из подвала.
5. **Мобифитнес.** Главная содержит личный кабинет, расписание — виджет расписания, сертификаты — переход в магазин кабинета. На стоимости кнопка ведёт к расписанию. Дополнительные виджеты в Тильде не нужны. В настройках клуба 9514 проверьте разрешённый домен, цвета #3769A8 и #C6CD4B, фильтры, остаток мест, SMS, права магазина и согласие при регистрации и оплате. Чекбокс страницы управляет доступом к встроенному интерфейсу. Подтверждение и хранение согласия в заказе настраиваются отдельно у провайдера. [Инструкция Мобифитнес](https://mobifitness.usedocs.com/article/48525).
6. **Обратная связь.** Форма в «Контактах» после заполнения и согласия открывает почтовую программу с адресом студии, сообщением, телефоном и текстом согласия. Для отправки посетитель подтверждает письмо. Если нужен приём в «Заявки» Тильды, замените форму внутри секции `#feedback` штатным блоком формы, назначьте получателя в «Настройки сайта → Формы» и подключите его к блоку. Перенесите обязательный чекбокс из `content.json → legal.consent` и ссылку `legal.policy`. Сохраните якорь `feedback` для ссылки в подвале.

## Приёмка владельцем на опубликованном поддомене

- На телефоне откройте меню и перейдите во все разделы. Разверните прайс и FAQ, проверьте телефоны, карту и форму. В новом приватном окне проверьте отсутствие запросов к счётчику сайта до согласия, включение после выбора аналитики и отключение в подвале.
- Тестовым клиентом пройдите регистрацию по SMS → покупку согласованного тестового абонемента → получение чека → автоматическое зачисление → запись из расписания → списание занятия → своевременную отмену. Сверьте остаток, историю и бонусы с данными клуба.
- В магазине выберите утверждённый сертификат, проверьте сумму, оплату, чек, получение PDF/кода по почте и активацию. Способ активации и срок должен подтвердить владелец. Зафиксируйте ID тестового заказа, результат и состояние баланса во внутреннем журнале студии.
- Проверьте PageSpeed Mobile на опубликованных страницах Тильды, целевой результат — не ниже 70. Повторите после подключения внешних сервисов.

## Обновление

Редактируйте `content.json`, затем запустите `python3 tools/generate.py`. Генератор обновит обе версии. Опубликуйте изменившиеся блоки. Для замены фото в T123 сначала сохраните новые файлы в репозитории, затем укажите SHA этого коммита в `ASSET_CDN` и повторите генерацию. Журнал шагов и реестр заглушек — в `PROGRESS.md`.

Дизайн основан на предоставленной спецификации [Ashleyandco · OpenDesign](https://opendesign.cc/packs/ashleyandco/). Шрифты Google Fonts — Source Serif 4 и Golos Text. Лицензии находятся рядом со шрифтами.
